# Stara Original Roles

This file set is original concept work for the Stara project and does not mirror any one mod role list.

## Scope
- 60 total entries in `roles.csv`
- 20 Crewmate roles
- 20 Impostor roles
- 12 Neutral roles
- 8 Modifiers

## Design Rules
- Role names and ability framing are project-original.
- Every role includes counterplay to avoid hard-solve states.
- Modifiers are intentionally lightweight for compatibility.
