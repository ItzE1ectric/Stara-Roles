# Stara Original Roles

This file set is original concept work for the Stara project and does not mirror any one mod role list.

## Scope
- 60 total entries in `roles.csv`
- 20 Crewmate roles
- 20 Impostor roles
- 12 Neutral roles
- 8 Modifiers

## Design Rules
- Role names and ability framing are project-original.
- Every role includes counterplay to avoid hard-solve states.
- Modifiers are intentionally lightweight for compatibility.

## Runtime Status
- `config/role_definitions.json` contains implementation-ready definitions for all 60 roles.
- `config/spawn_weights.json` contains spawn caps, role/modifier weights, and conflict pairs.
- `config/cooldowns.json` contains per-role cooldown, duration, and charges.
- `config/lobby_presets.json` contains three ready-to-run lobby presets.
